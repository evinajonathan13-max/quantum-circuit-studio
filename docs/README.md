# Quantum Circuit Studio documentation

This directory contains the complete documentation for the local-first Quantum Circuit Studio research prototype.

| Guide | Read it when you need to… |
|---|---|
| [Getting started](GETTING_STARTED.md) | install the studio, create a first graph and navigate the workspace. |
| [Architecture](ARCHITECTURE.md) | understand the local JSON model, code organisation and view projections. |
| [Validation](VALIDATION.md) | interpret local checks, frequency states, crosstalk scores and model limits. |
| [Exports](EXPORTS.md) | select JSON, OpenQASM, STL or STEP for a correct next handoff. |

The diagrams in `images/` are deterministic renders of the Mermaid sources in `diagrams/`. Keeping source and rendered asset together means that a future change can update the exact same visual explanation instead of replacing it with an opaque image.
