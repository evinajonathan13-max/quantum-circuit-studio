# Documentation visual assets

The documentation contains two types of visual evidence.

| Asset family | Source | Purpose |
|---|---|---|
| `images/*.png` | Deterministic render of the Mermaid sources in `diagrams/`. | Explain architecture, model projections and validation boundaries precisely. |
| `images/screens/*` | Clean local browser captures of the bundled `transmon-microcell` demonstration. | Show the real interface states for Schematic, Topology 3D, Layer Stack and Frequency Map. |

The screenshots show the local demonstration model only. They are documentation of the interface and must not be interpreted as electromagnetic, calibration or fabrication evidence.
